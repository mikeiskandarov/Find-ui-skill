# Find UI

**Опиши нужное взаимодействие — найди подходящий компонент.**

Скилл для Codex, который ищет UI-компоненты и референсы взаимодействий в подборке любимых библиотек. Понимает запросы на русском и английском, проверяет подходящие варианты и возвращает короткий список с прямыми ссылками.

[English](README.md) · [Каталог](references/index.md) · [Инструкции скилла](SKILL.md)

## Установка

Попроси Codex:

```text
$skill-installer Установи скилл из https://github.com/mikeiskandarov/Find-ui-skill
```

Или установи через Git:

```sh
mkdir -p ~/.agents/skills
git clone https://github.com/mikeiskandarov/Find-ui-skill.git ~/.agents/skills/find-ui
```

Если папка уже существует, сначала проверь установленную версию. Для установки только в одном проекте используй его папку `.agents/skills/find-ui`.

Если скилл не появился, перезапусти Codex. Он вызывается явно через `$find-ui`. Пути установки описаны в [официальной документации](https://learn.chatgpt.com/docs/build-skills).

## Примеры

```text
$find-ui Найди компонент с анимацией добавления и удаления строк кода.

$find-ui Найди индикатор этапов работы AI-агента: ожидание, выполнение, успех и ошибка.

$find-ui Нужен переключатель с пружинной анимацией и открытым исходным кодом.

$find-ui Найди чатовый инпут с вложениями и выбором модели.
```

Скилл сначала ищет в локальном каталоге, затем проверяет документацию, доступный исходный код и живое демо. В ответе — 1–3 варианта, ссылки, доступность исходников, что удалось проверить и что придётся адаптировать.

Красные и зелёные строки в diff ещё не означают анимацию изменения кода. Скилл отдельно проверяет такие детали и сообщает, если поведение не подтверждено.

## Требования и ограничения

Для локального поиска нужен Python 3, без дополнительных пакетов и API-ключей. Для проверки актуальной документации агенту нужен доступ к интернету, а для проверки анимации — управление браузером. Если доступа нет, результат должен быть обозначен как непроверенный.

Поиск не устанавливает UI-пакеты, не меняет проект и не покупает доступ. Реализацию компонента нужно запросить отдельно. Каталог содержит описания и ссылки; лицензии и условия исходных библиотек сохраняются.

## Поиск из терминала

Из папки репозитория:

```sh
python3 scripts/search.py "переключатель" --limit 5
python3 scripts/search.py "code diff line-add line-remove" --limit 5
python3 scripts/search.py "chat input" --library prompt-kit --limit 3
```

Результат выводится в JSON. Это поиск по словам и тегам, а не семантическая модель. Пустая выдача не доказывает отсутствие подходящего компонента.

## Обновление

```text
$find-ui обнови каталог
```

Каталог обновляется только по явному запросу. Обычный поиск не перезаписывает файлы и не запускает фоновую синхронизацию.

## Предложить улучшение

Открой issue или pull request со ссылкой на официальный источник и описанием проверенного поведения. При правке записей сохраняй английские описания, русские и английские поисковые синонимы, дату и ограничения проверки. Подробности — в [процедуре обновления](references/update.md).
