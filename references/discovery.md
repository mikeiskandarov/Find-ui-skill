# Discovery maps

Verified: 2026-10-15. These sources are part of the curated collection, but deliberately do not have exhaustive component inventories.

## 21st

Use the [component catalog](https://21st.dev/community/components), [library directory](https://21st.dev/community/libraries), and the relevant category below. Use the site's search for exact interaction terms; alternatively search the web with `site:21st.dev` and those terms. Open the actual author's component page and verify its demo and source. Do not treat all marketplace components as one library or assume one license.

The [official llms.txt](https://21st.dev/llms.txt) documents `.md` versions of component/category pages. Source retrieval can have account limits or paid requirements; check the current page and [pricing](https://21st.dev/pricing). Do not install the CLI/MCP or sign up just to search.
